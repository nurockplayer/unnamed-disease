# 人類盲測指南

## 試玩連結

請把這個網址直接傳給試玩者：

**https://nurockplayer.github.io/unnamed-disease/**

全案約 15–20 分鐘。請找一位沒看過遊戲內容、也沒參與製作的人，讓他自行開啟網址遊玩。

## 進行方式

- 開始前只說「請照你自己的想法玩，玩到結尾後告訴我感受」，不要解釋遊戲設計、歷史背景或正確答案。
- 過程中盡量不幫忙、不提示下一步，也不要替玩家操作。玩家提問時可以回「照你覺得合理的方式試試看」。
- 安靜觀察，記下玩家在哪裡停頓、來回查看、猶豫、誤解目標或想放棄。記錄大約時間與當時畫面／操作即可，不必錄影。
- 讓玩家完成全案，約 20 分鐘；若中途想停，尊重玩家，記下停在哪裡與原因。
- 結尾的「試玩回饋」可以由玩家自己填答。若透過聊天傳送，請讓玩家按「複製回饋」後貼回給你；也可以請他選擇「在 GitHub 回報」。

## 回饋方式

結案畫面的回饋區會自動附上遊玩時間、各謎題解出前的錯誤／部分推論次數與版本識別。玩家可用「複製回饋」貼到聊天，不需要 GitHub 帳號；也可以透過「在 GitHub 回報」預填問題內容。若從 GitHub 開始，請使用[試玩回饋表單](https://github.com/nurockplayer/unnamed-disease/issues/new?template=playtest.md)。

請保留玩家原話，並一併轉交觀察到的停頓或卡住位置。不要只整理成「喜歡／不喜歡」。
