# Decisions — 設計決策與來源

2026-10-19 JST 初始基準。決策記錄可以修改，**區分 Owner 明確選定與 Game Director 的可逆工程決定**，避免把早期 brainstorming 誤當永久規則。

## D001 — 系列定位

- **Owner 共識**：不是傳統課本科學遊戲；科學、醫學、航海、金融與工程都可被改編為有完整懸疑／冒險故事的篇章。
- **意圖**：玩家先喜歡角色、情節與玩法，之後不知不覺理解證據與科學方法。
- **備註**：系列正式名稱仍未定；《JIMON／時問》《霧中》等僅為候選。原《Tachiko: Before We Knew》不視為不可修改的上市名稱。

## D002 — 首作題材

- **已確認方向**：首作優先《沒有名字的病》1854 年倫敦霍亂懸疑，先以可玩原型與外部回饋驗證吸引力。
- **未承諾**：放棄愛丁頓 1919 觀測題材；它是後續可共用推理系統的第二款候選。

## D003 — 玩法先 A 後 C（Owner 明確選擇）

- **已確認**：A 定點調查＋證據推理先做得好玩，才升級 C 混合式場景／角色演出。
- **理由**：四天內把時間用在真推理和完整故事，而非移動控制與龐大場景。
- **禁止誤解**：不是否定遊戲氣氛、美術或人物，而是先後次序。

## D004 — 四天 MVP（目標，非完成狀態）

- 2026-10-19–10-22 JST：先做 Day 1 的 4–6 分鐘真推理，再推進 15–20 分鐘獨立試玩。
- 真正能走通、可回歸、史實可信且有外部試玩優先。第二款不是四天內強制交付。
- Opus 擔任 Game Director，可委派 Sol/Codex；pnpm，不使用 npm。
- **引擎未定**：Phaser/TypeScript 與純 DOM/TypeScript 是 PoC 候選，Opus 可以做出更合理的方案並紀錄。

## D005 — 歷史與虛構不能混淆

- 史實：John Snow 1849 已持水源傳播說；1854 年 Broad Street 9/7 提出論據、9/8 把手移除；啤酒廠、濟貧院、Hampstead 病例有原始記錄。
- 戲劇：玩家為虛構紀錄助手，對話與遊戲文書多為重建。
- 禁止：虛構陰謀抹黑真實人物；把 1855 地圖送回 1854 當作完工文件；聲稱啤酒能防霍亂；聲稱移除把手立刻終止疫情。
